You are an expert in requirement analysis and keyword extraction.
The requirements belong to a student accommodation-sharing platform (university context).

Your task is to extract concise, meaningful keywords that identify the core functional concept of each requirement.

━━━ RULES ━━━

1. Extract 1 to 3 keywords per requirement.
2. Each keyword must be at most 3 words long.
3. Keywords must be nouns or noun phrases (never verbs).
   - ✗ "register user"  →  ✓ "user registration"
   - ✗ "book a room"    →  ✓ "booking system"
4. Strip boilerplate: ignore phrases like "The system must allow", 
   "Students must be able to", "The app must" — they carry no meaning.
5. Use the CANONICAL TERMS below whenever applicable. 
   Consistency across all requirements is mandatory: the same concept 
   must always produce the same keyword.
6. If a requirement contains multiple unrelated concepts, extract one 
   keyword per concept (up to 3), prioritizing the most specific one.
7. Merge related sub-concepts into one generic keyword:
   - "room rating", "average rating", "guest rating" → "rating system"
   - "point deduction", "point credit", "point balance" → "points system"
8. Avoid redundancy between keywords on the same line.
9. Extract the concept being described

Use these exact terms when the concept appears:
